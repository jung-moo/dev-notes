# 프로세스 메모리

## 핵심

[[process]]가 실행되면 운영체제로부터 메모리 공간을 할당받는다.

일반적인 프로세스의 메모리 구조는 다음과 같이 구분해서 이해할 수 있다.

```
높은 주소
┌──────────────┐
│    Stack     │
│      ↓       │
├──────────────┤
│              │
│              │
│      ↑       │
│     Heap     │
├──────────────┤
│     Data     │
├──────────────┤
│     Code     │
└──────────────┘
낮은 주소
```

각 영역은 저장하는 데이터의 특성과 수명이 다르기 때문에 나누어 관리한다.

## Code

프로그램이 실행할 **명령어(코드)**가 저장되는 영역이다.

작성한 소스 코드는 컴파일 과정을 거쳐 CPU가 실행할 수 있는 명령어 형태로 변환되고, 실행 시 Code 영역에 배치된다.

실행 중인 코드가 임의로 변경되는 것을 방지하기 위해 일반적으로 읽기 전용으로 관리된다.

## Data

프로그램이 실행되는 동안 유지되는 **전역 변수와 정적 변수 등의 데이터**가 저장되는 영역이다.

프로세스가 시작될 때 생성되고 프로세스가 종료될 때까지 유지된다.

## Heap

프로그램 실행 중 **동적으로 할당되는 메모리**가 사용되는 영역이다.

필요한 크기와 수명을 실행 중에 결정할 수 있다.

예를 들어 C에서는 `malloc()`을 이용하여 Heap 메모리를 할당할 수 있다.

```
int *p = malloc(sizeof(int));
```

Heap에 할당된 메모리는 Stack과 달리 함수가 종료된다고 자동으로 제거되는 것은 아니다.

언어와 실행 환경에 따라 직접 메모리를 해제하거나 Garbage Collector와 같은 메모리 관리 기능을 사용한다.

Java의 객체와 Garbage Collection에 대한 내용은 [[jvm-memory]]에서 다룬다.

## Stack

함수 또는 메서드 호출과 관련된 정보를 관리하는 영역이다.

함수가 호출되면 해당 호출에 필요한 Stack Frame이 생성되고, 함수가 종료되면 제거된다.

Stack Frame에는 일반적으로 다음과 같은 정보가 포함될 수 있다.

- 지역 변수
    
- 함수의 매개변수
    
- 반환 주소
    
- 함수 호출과 관련된 정보
    

```
함수 호출
   ↓
Stack Frame 생성
   ↓
함수 실행
   ↓
함수 종료
   ↓
Stack Frame 제거
```

Stack은 함수 호출의 수명에 맞춰 메모리를 빠르게 관리할 수 있다.

## Heap과 Stack의 차이

Heap과 Stack을 구분하는 핵심적인 이유 중 하나는 **데이터의 수명이 다르기 때문**이다.

|Stack|Heap|
|---|---|
|함수 호출과 관련된 메모리|동적으로 할당되는 메모리|
|함수 호출 시 Frame 생성|필요할 때 메모리 할당|
|함수 종료 시 Frame 제거|함수 종료와 독립적인 수명 가능|
|지역 변수 등이 저장됨|동적으로 생성된 데이터가 저장됨|

예를 들어 함수 내부에서 만들어진 데이터라도 함수가 종료된 이후까지 사용해야 한다면 Stack의 수명만으로는 관리하기 어렵다.

Heap은 이러한 데이터를 함수 호출의 수명과 독립적으로 관리할 수 있게 해준다.

## Java와의 관계

Java 프로그램도 결국 운영체제에서 실행되는 [[process]]이다.

하지만 Java 프로그램은 JVM 위에서 실행되기 때문에 Java 개발자가 다루는 Heap과 Stack은 일반적인 프로세스 메모리 구조와 완전히 동일한 개념으로 보면 안 된다.

JVM은 Java 프로그램을 실행하기 위해 자체적인 런타임 메모리 영역을 관리한다.

```
운영체제
    ↓
JVM 프로세스
    ↓
JVM Runtime Data Areas
    ├── Heap
    ├── Java Stack
    ├── Method Area
    ├── PC Register
    └── Native Method Stack
```

Java의 객체, 지역변수, GC, `-Xms`, `-Xmx`, `-Xss` 등은 [[jvm-memory]]에서 다룬다.
