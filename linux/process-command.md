# Linux 프로세스 관련 명령어

## 핵심

Linux에서는 `ps`, `grep`, `tail`, `kill` 등의 명령어를 이용하여 프로세스를 확인하거나 로그를 조회하고 프로세스를 종료할 수 있다.

프로세스, PID, PPID 등의 개념은 [[process|프로세스]]에서 다룬다.

## ps

`ps`는 현재 실행 중인 프로세스의 정보를 확인하는 명령어이다.

```
ps
```

기본 `ps`는 현재 터미널과 관련된 프로세스 위주로 보여준다.

실무에서는 전체 프로세스를 자세히 확인하기 위해 다음 명령어를 자주 사용한다.

```
ps -ef
```

### `-e`

시스템에서 실행 중인 **모든 프로세스**를 조회한다.

### `-f`

프로세스 정보를 **상세한 형식(Full Format)**으로 출력한다.

따라서 다음 명령어는

```
ps -ef
```

모든 프로세스를 상세한 형식으로 조회한다는 의미이다.

출력은 다음과 같은 형태이다.

```
UID      PID   PPID  C  STIME  TTY  TIME      CMD
user     1002  1001  2  20:57  ?    00:01:30  /path/to/java ...
```

주요 항목은 다음과 같다.

- `UID` : 프로세스를 실행한 사용자
    
- `PID` : 프로세스 ID
    
- `PPID` : 부모 프로세스 ID
    
- `C` : CPU 사용 관련 값
    
- `STIME` : 프로세스 시작 시각
    
- `TTY` : 연결된 터미널
    
- `TIME` : 누적 CPU 사용 시간
    
- `CMD` : 프로세스를 실행한 명령어와 인자
    

## grep

`grep`은 입력된 내용에서 **특정 문자열이 포함된 행을 찾는 명령어**이다.

```
grep <검색할_문자열> <파일_경로>
```

예를 들어 다음과 같이 사용할 수 있다.

```
grep ERROR application.log
```

`application.log`에서 `ERROR`가 포함된 행을 찾는다.

## Pipe

`|`는 앞 명령어의 출력 결과를 뒤 명령어의 입력으로 전달한다.

```
<명령어1> | <명령어2>
```

예를 들어 다음 명령어는

```
ps -ef | grep java
```

다음 순서로 동작한다.

```
ps -ef
→ 전체 프로세스 조회
→ 결과를 grep에 전달
→ java가 포함된 행만 출력
```

따라서 특정 프로세스를 찾을 때 다음 형태로 사용할 수 있다.

```
ps -ef | grep <검색할_키워드>
```

## tail

`tail`은 파일의 **마지막 부분을 출력하는 명령어**이다.

로그 파일의 최근 내용을 확인할 때 자주 사용한다.

```
tail <파일_경로>
```

기본적으로 파일의 마지막 10줄을 출력한다.

### 출력할 줄 수 지정

```
tail -100 <파일_경로>
```

파일의 마지막 **100줄**을 출력한다.

다음과 같이 작성할 수도 있다.

```
tail -n 100 <파일_경로>
```

### 실시간 로그 확인

```
tail -f <로그_파일_경로>
```

`-f`는 파일에 새로운 내용이 추가될 때마다 계속해서 출력한다.

서버 로그를 실시간으로 확인할 때 자주 사용한다.

```
애플리케이션이 로그 기록
        ↓
로그 파일에 내용 추가
        ↓
tail -f가 새로운 내용 출력
```

종료하려면 일반적으로 `Ctrl + C`를 사용한다.

## kill

`kill`은 프로세스에 **시그널(Signal)을 보내는 명령어**이다.

프로세스를 종료할 때 주로 사용한다.

```
kill <PID>
```

예:

```
kill 12345
```

기본적으로 `SIGTERM` 시그널을 보내 프로세스가 정상적으로 종료될 기회를 준다.

### 강제 종료

```
kill -9 <PID>
```

`SIGKILL`을 보내 프로세스를 즉시 강제 종료한다.

프로세스가 정상적인 종료 처리를 수행할 기회를 갖지 못하므로 **일반적인 종료 방법으로 먼저 시도한 뒤 필요한 경우에만 사용한다.**

```
kill <PID>
→ 정상 종료 요청

kill -9 <PID>
→ 강제 종료
```

## 프로세스 확인 흐름

특정 프로세스를 확인하고 로그를 살펴보는 상황에서는 다음과 같은 흐름으로 사용할 수 있다.

```
1. 프로세스 확인
   ps -ef | grep <검색할_키워드>

2. PID / PPID / CMD 확인

3. 최근 로그 확인
   tail -100 <로그_파일_경로>

4. 실시간 로그 확인
   tail -f <로그_파일_경로>

5. 필요한 경우 프로세스 종료
   kill <PID>
```

PID와 PPID의 의미 및 부모-자식 프로세스 관계는 [[process|프로세스]]를 참고한다.
